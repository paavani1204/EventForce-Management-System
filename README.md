# EVENTFORCE MANAGEMENT SYSTEM

## 📌 Project Overview

EventForce Management System is a Salesforce-based event management platform designed to streamline event planning, client management, venue coordination, and vendor operations through a centralized system.

The system helps event teams manage important event information efficiently and provides a structured platform for coordinating different event-related activities.

## 🎯 Project Objective

The main objective of EventForce Management System is to simplify event management by maintaining client, event, venue, and vendor information in one centralized Salesforce platform.

## ⚙️ Key Features

* Client Management
* Event Management
* Venue Management
* Vendor Management
* Centralized Event Information
* Salesforce Automation
* Data Management using Salesforce Objects
* Event Operations Tracking

## 🛠️ Technologies Used

* Salesforce
* Salesforce Lightning
* Salesforce Objects
* Salesforce Flow
* Apex
* Git
* GitHub
